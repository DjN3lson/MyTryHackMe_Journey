# TryHackMe Cybersecurity Journey

This repository documents my cybersecurity learning journey through TryHackMe, focusing on developing practical, hands-on skills through guided labs, challenges, and security-focused exercises.

The goal of this repository is to track my progress, document the concepts and techniques I learn, and build a practical reference of my cybersecurity experience. It covers topics ranging from foundational security concepts and networking to Linux, Windows security, web application security, reconnaissance, vulnerability assessment, privilege escalation, authentication, cryptography, and penetration testing.

Each section may include notes, methodologies, commands, tools, observations, and solutions developed while completing TryHackMe rooms and learning paths. The repository is intended to demonstrate my continuous development of practical cybersecurity skills while providing a structured record of my progress.
